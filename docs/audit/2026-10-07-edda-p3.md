# P3: Pocket Editor ↔ Open Edda

Дата: 2026-10-07. Изменения выполнены в текущей ветке `retain/2026-09-29-WritingTools-pocket-editor-155350`, поверх `f4aa28e`.

## Реализовано

- Выбор провайдера → аккаунта → проекта → расположения; для Яндекса сохранён текущий аккаунт и выбор папки.
- Несколько серверов/аккаунтов Edda, несколько книг из одного проекта и книги из разных проектов.
- Общий шлюз загрузки/синхронизации, маршрутизация по постоянной привязке книги.
- Раздельный кэш копий с одинаковым исходным `book_id`; исходные ID книги, глав и рецензий сохраняются на сервере.
- Проверка SHA-256, атомарная публикация через версию проекта, восстановление потерянного ответа по операции, кооперативные блокировки.
- Существующий офлайн-редактор рецензий, слияние и проверки anchors используются без изменения публичных схем. Синхронизация не меняет Markdown.
- Расширяемый каталог: Seafile — следующий; Dropbox, OneDrive, Box, Google Drive — будущие адаптеры, ещё не реализованы.

После первого обновления PR CI обнаружил девять проверок старых подписей Яндекс Диска и одну проверку файла вне видимой области списка. Состояния синхронизации, заметки, варианты конфликтов и ошибки теперь доступны через типизированные Compose semantics; действия выбора источника и папки — через стабильные tags. Проверки причин ошибок не сравнивают текст. Отдельный тест подтверждает сохранение кода конфликта при смене языка сообщения.

Старое локальное падение `BookFlowTest.longContentsReorderKeepsDraftViewportAwayFromCurrentChapter` воспроизводилось и на исходном HEAD `f4aa28e`. Исправлена начальная прокрутка теста: перетаскиваемая глава и её целевая позиция остаются внутри видимой области. Проверки итогового порядка и отсутствия скачка к первой главе сохранены. Финальный полный Android-прогон прошёл.

В обмене использовались только синтетические книги и временный сервер. Реальные аккаунты и проекты не изменялись. GUI Galley Desk и авторизация через настоящий Яндекс OAuth не проверялись; существующий Яндекс-код покрыт JVM-набором, а интерфейс его выбора — Android-тестами.

Воспроизводимый сценарий и устройство интеграции: [источники книг и Edda](../edda.md).
