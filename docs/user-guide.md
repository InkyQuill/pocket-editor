# Руководство пользователя Pocket Editor

## Вход и добавление книги

Нажмите «Войти через Яндекс», завершите авторизацию и выберите действие «Выбрать папку» с Markdown. Для сырой папки первоначальный порядок глав строится детерминированно по пути, нормализованному для сравнения; отдельный экран выбора названий и порядка не появляется.

## Первая загрузка

В библиотеке появляется компактная карточка `0 из N`. Первые `min(3, N)` глав становятся доступны для чтения, затем остальные главы загружаются последовательно в фоне. Если открыть незакэшированную главу из Содержания, она получает приоритет; после этого загрузка продолжится с ближайшей ожидающей главы.

Карточка предлагает «Пауза», «Продолжить», «Отменить» и «Повторить». Отмена прекращает текущую установку; повтор нужен после временной ошибки.

## Чтение и навигация

Используйте «Содержание» для перехода между главами и переключатель книг для возврата в библиотеку. «Поиск» ищет по источнику, «Оформление» меняет параметры чтения, а позиция чтения сохраняется локально. Незакэшированная глава показывает загрузку, пока получает приоритет.

## Рецензирование

В чистом режиме виден только канонический текст. В режиме «Рецензирование» можно создавать сигналы фрагмента, необязательные комментарии, правки и заметки главы. Несохранённые черновики восстанавливаются после возврата и перезапуска. Конфликты видны явно и требуют выбора пользователя; приложение не угадывает спорную привязку.

## Изменение порядка глав

Для изменения порядка используйте отдельное действие «Изменить порядок глав» в Содержании. Это меняет сохранённый список глав, но не переименовывает и не изменяет Markdown-файлы.

## Работа без сети

После загрузки книга читается без сети. Без подтверждённого соединения нельзя выполнить новые сетевые запросы или синхронизацию, но уже закэшированные главы, поиск и локальные черновики остаются доступны.

## Удаление локальной копии

«Удалить с устройства» удаляет полный локальный кэш книги, индекс и рабочее состояние. Удалённые файлы на Яндекс Диске, включая Markdown, манифест и рецензии, не удаляются.

## Восстановление после ошибок

- Если требуется авторизация, снова «Войти через Яндекс»; токен не показывайте и не копируйте в отчёты.
- При отсутствии подтверждённой сети проверьте доступ в интернет и повторите операцию позже.
- При временно недоступном сервисе нажмите «Повторить» после восстановления сервиса.
- При некорректных удалённых данных не продолжайте синхронизацию: исправьте исходные данные в удалённой папке или обратитесь к владельцу книги.
- При явном конфликте синхронизации выберите видимый вариант в интерфейсе; не удаляйте рабочие sidecar-файлы вручную.
