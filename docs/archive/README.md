# Архив документации Pocket Editor

## Назначение

Этот каталог сохраняет хронологию решений и работы над Pocket Editor. Архивные
файлы могут содержать устаревшие команды, ветки, пути, статусы и предположения;
они не являются актуальными инструкциями.

## Состав архива

- `plans/` — исторические планы реализации.
- `specs/` — проектные спецификации, сопровождавшие эти планы.
- `project-history/` — прежние записи о состоянии проекта, проверках и
  незавершённой работе.

## Как пользоваться архивом

Используйте архив для исследования причин прежних решений и последовательности
изменений. Перед выполнением команд или продолжением работы сверяйтесь с
текущей документацией: указанные в архиве ветки, пути и состояние проекта могли
измениться.
